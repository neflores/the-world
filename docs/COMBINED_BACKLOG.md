# World — объединённый план

Источники: GitHub issues #1 (Git workflow), #2 (World-core, 55 разделов),
World Full Vision и список из 33 недостающих функций. Issue #2 определяет
архитектурный этап; его non-goals переходят в последующие продуктовые этапы,
поскольку владелец отдельно поручил объединить и реализовать оба списка.

Правила: AltarAppsReborn остаётся без изменений; каждый завершённый логический
шаг проверяется, коммитится и отправляется отдельно. Production-операции
выполняет host через адаптер; локальная simulation не выдаётся за backend.

Критерий завершения механики: доступна в Playground, использует общий runtime
и типизированные контракты, реагирует на обновление проекции и имеет проверку
ключевых инвариантов. Наличие модели/кнопки-заглушки не считается завершением.

Подключение настоящих записей и маршрутов внутри AltarAppsReborn требует
отдельного изменения того проекта. Здесь можно реализовать и проверить весь
контракт и адаптерный стенд, сохраняя запрет на изменение host.
