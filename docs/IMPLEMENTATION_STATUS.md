# Применение полного видения

Это статус версии 0.2, а не утверждение о завершении всех 40 разделов vision.
Будущие расширения документа не превращены в фиктивные работающие backend-функции.

| Область vision | Состояние 0.2 |
| --- | --- |
| География / города | Реальная региональная география Израиля; вымышленные города, направление и постоянный plot каждого места |
| Стабильный каркас | Central Square, Favorites Square, Online Portal, Craft District; дополнительные кварталы при росте |
| Клубы / сообщества / мастера / ремесленники | Отдельные виды мест и стабильные ID; демонстрационные записи через общий provider |
| Добавление клуба | Валидируемая форма, обязательный адрес, направление, оформление; локальное сохранение Playground |
| Таверна | Отдельный иллюстрированный главный зал, вывеска, official/community boards, recruitment tables |
| Наборы | Свободные места и проекции состава, только будущие открытые игры; полный/закрытый набор исключается |
| Presence / NPC | Автоматическая прогулка по разрешённым коридорам, статусы, карточка, hidden/recent trace с fade до 15 минут |
| Социальные действия | Типизированные Profile/Message/Invite intents; разрешения действий из проекции; реальной отправки сообщений в demo нет |
| Оформление | Один рендерер карты и preview; шаблон здания + banner/plants/festival, apply/cancel |
| Камера | Общий transform сцены/объектов, hover/focus, pan/zoom/reset, переход к месту из списка |
| Доступность | Текстовый список, клавиатурные элементы, Reduced Motion, Quiet Mode, проверка узкого экрана и увеличенного текста |
| Архитектура | Отдельные модели, data source, layout, renderer, runtime, Flutter widgets и simulation; без part-монолита |
| Host integration | Контрактная проверка с реальным Altar DTO; реальный backend adapter ещё не подключён |

## Следующие продуктовые этапы

- Авторский avatar editor, idle/group/board-interest state machine и представители
  мастеров разных tiers. Сейчас два готовых набора анимации персонажей.
- Настоящие Community board notes/drawings, временные speech bubbles,
  реакционные эффекты и агрегация. Пока доска отправляет действие наружу.
- Полные theme/slot catalog, trophy/bar/table skin/representative, locked states,
  tiers и operational flags из безопасной проекции host.
- Дополнительные залы по времени, recurring/event halls; сейчас главный зал
  показывает до девяти столов и переводит остальные наборы на обычную доску.
- Время суток, сезонные состояния и временные festival/event projections;
  сейчас доступен статический festival appearance.
- Расширенные детерминированные сценарии simulation, low-FPS режим и profiling.
- Host localization/RTL regression suite, интеграция сообщений/заявок/Rooms,
  проверки на остальных целевых платформах.
- Поздний online-world с языковыми архипелагами, явно обозначенный в vision
  как будущий слой. Сейчас портал открывает список online-наборов.
